# 寻客 · 找客户工具

从抖音、小红书、快手翻评论，按意向把人分成 A / B / C 三档，联系方式整理成表。
写上你在做什么，搜索词自动配好。数据只存在你自己电脑上，不上传云端。

## 使用

**Windows**：解压 → 双击「第一次安装.bat」（仅首次）→ 双击「启动.bat」。

**macOS**：双击 dmg 挂载 → 双击「安装.command」（仅首次）→ 打开「寻客.app」。

打开后写上行业描述，选好平台，开始找客户。
